EMBLEM-NLP is the public entrypoint for Emblem Projects Inc. agent infrastructure, repository catalogs, AV and venue systems, document tooling, and applied AI workflows.

Most repositories in this organization are private. Public catalog links may show a GitHub 404 or login wall unless your GitHub account has been granted access.

## Access

Request access here:

[Request repository access](https://github.com/EMBLEM-NLP/.github/issues/new?template=access-request.yml)

Please keep requests non-confidential. Do not include passwords, secrets, client files, private project details, or controlled information in a public issue.

## Public Policy

The public organization profile is an index and access pathway. Source code, client work, internal documentation, and operational tooling generally live in private repositories. Public repositories are used only when a project is intentionally open-source, externally shareable, or required for GitHub profile/site behavior.
