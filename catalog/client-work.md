# Client Work

Public pointer page for confidential project work, controlled deliverables, and private client or project repositories.

Specific client repository names are not enumerated on the public catalog unless they are already intended to be public. Credentialed collaborators should request access by category or known repository name.

| Area | Scope | Access |
|---|---|---|
| Client deliverables | Project files, notes, documents, and delivery materials | Private |
| Controlled research | Internal research notes and project-specific analysis | Private |
| Site and permit workflows | Existing-condition review, documentation, and coordination material | Private |
| Confidential operations | Client-specific workflows and operating documents | Private |
